# Hotel Booking Cancellation Prediction System

## Project Overview
An academic group project that uses Machine Learning to predict whether a hotel reservation is likely to be cancelled. The trained model is integrated into a Django web application.

## Technologies
- Python
- Django
- Scikit-learn
- Pandas
- Joblib
- Machine Learning

## Dataset
- 119,390 hotel booking records
- Data cleaning and missing-value handling
- Exploratory Data Analysis (EDA)
- Feature selection

## Machine Learning Model
- Algorithm: Decision Tree Classifier
- Training / Testing Split: 70% / 30%
- Accuracy: 72.28%
- F1 Score: 55.7%
- Evaluation: Accuracy, F1 Score, Confusion Matrix

## Features
- Booking cancellation prediction
- Interactive dashboard displaying booking statistics
- Form-based prediction interface
- Integration between a trained ML model and Django

## Web Application
The Django application contains:
1. Dashboard — Total bookings, cancellations, cancellation rate and hotel statistics.
2. Prediction — Accepts booking details and returns a cancellation prediction.
